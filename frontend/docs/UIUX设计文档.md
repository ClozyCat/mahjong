# 🀄️ Web端麻将前端 UI/UX 设计交接规范 (Handoff Document)

## 1. 设计理念与全局基调
本项目的核心产品定位为**“新中式雅奢”**，旨在抛弃传统棋牌游戏的“市井喧闹感”与“重度3D拟真”，通过**极简几何、克制留白、水墨光影**与**空灵音效**，打造一款兼具东方古典气韵与现代数字美学的高端 Web 游戏体验。

* **核心气质：** 典雅、高端、优美、明快、呼吸感。
* **技术导向：** 移动端横屏优先，极致的 Web 性能（全面拥抱 CSS3 特性，摒弃大型序列帧和重度位图）。

---

## 2. 视觉与材质规范 (Visual & Material)

### 2.1 全局色彩系统 (Color Palette)
摒弃大红大紫与高饱和度对比，采用低饱和、高明度的中国传统色系组合：
* **背景主色：** 暖素白/纸帛色 (`#F9F9F7` -> `#EAEAE4`)
* **文字与骨架：** 墨黑色 (`#2C3539`)，用于全局文字、牌面线条。
* **点缀色 (高亮/强调)：** * 哑金色 (`#B8975E`)：用于边框、UI提示、倒计时环。
    * 朱砂红 (`#9A3B2A`)：用于“万”字红牌、“胡”牌按钮、高光结算文字。
    * 黛绿色 (`#365B48`)：用于“条”子牌线条。

### 2.2 背景材质 (CSS-Only)
**严禁使用大尺寸背景图片**。背景需通过 CSS 模拟“绢丝水墨”质感：
* **水墨晕染：** 使用多重 `radial-gradient`（径向渐变）在屏幕对角制造淡淡的青灰与墨蓝色光晕。
* **绢丝肌理：** 使用 SVG 的 `<feTurbulence>` 滤镜生成微弱噪点，叠加在渐变底层，提供高分辨率下不失真的布料摩擦感。

### 2.3 UI 面板材质
所有的浮层（玩家信息、设置菜单）一律采用**高通透度毛玻璃 (Frosted Glass)**：
* `background: rgba(255, 255, 255, 0.4);`
* `backdrop-filter: blur(12px);`
* 配合 1px 的极细金色半透明边框 `rgba(184, 151, 94, 0.2)`。

## 3. 麻将牌面设计：几何极简 (Tile Design)

保留麻将识别骨架，剥离写实图案，进行彻底的几何与线条化重塑。

* **牌体本身：** 采用温润的微拟物风（Neumorphism），纯白底色配合极浅的灰色阴影，制造“放在绢丝上”的轻薄立体感。圆角收敛，比例修长。
* **字牌 & 万字：** 抛弃楷体毛笔字，全量替换为极细的现代无衬线体（Sans-serif）或现代宋体，字重控制在 200-300。
* **筒子 (Dots)：** 设计为极简的“几何同心圆”，使用 1.5px 线条绘制。一筒为带有虚线射线的放大同心大圆。
* **条子 (Bamboos)：** 简化为纯粹的圆角直线条（胶囊体）。一索（一鸟）重绘为由几何三角形拼接的“折纸风飞鸟”。
* **白板：** 一个带有极细金色描边的空心矩形框。

## 4. 空间与布局逻辑 (Layout & Hierarchy)

采用严格的 **2D 正交俯视图**，空间布局以“信息降噪”和“移动端防误触”为第一准则。

### 4.1 核心层级
* **1级视觉中心：** 玩家手牌（尺寸最大，位于屏幕底部 35% 区域）。
* **2级信息：** 中央弃牌池（牌海）与各家副露区（吃碰杠明牌）。
* **3级盲盒信息：** 对手的手牌背面（缩小为纯色线框或色块，仅作数量示意）。

### 4.2 细节规范
* **最新弃牌高亮：** 中央弃牌池最新打出的一张牌，需叠加 CSS `animation` 实现一圈金色的“呼吸动态边框”，引导视觉焦点。
* **副露区指向：** 吃碰的牌必须明确来源（如碰上家的牌，最左侧一张需逆时针旋转 90 度横放）。
* **刘海屏安全区：** 左右两侧 UI 必须使用 CSS `env(safe-area-inset-left/right)` 进行内边距限制。

## 5. 交互与动效体验 (UX & Motion)

### 5.1 大拇指黄金操作区
* **出牌逻辑：** 符合直觉的“单手拖拽”。点击手牌微微弹起放大，此时全图高亮同名牌；再次点击或**向上滑动 (Swipe up)** 完成出牌。无需额外的“出牌”按钮。
* **操作按钮 (吃/碰/杠/胡)：** 悬浮于屏幕右下角安全区，成弧形或水平排列，确保右手大拇指可盲操。

### 5.2 物理隐喻动效
* **开局入场 —— “画卷展开”：** 使用 CSS `clip-path` 从屏幕中轴线向两侧平滑裁剪展开，过渡曲线应起手慢、中间快、收尾缓，极具仪式感。
* **胡牌/高光 —— “水墨晕染”：** 胡牌瞬间画面停滞，使用 CSS `-webkit-mask-image: radial-gradient` 从指定点向全屏炸开墨色遮罩，过渡出结算界面。
* **思考倒计时 —— “金环流沙”：** 摒弃数字读秒。在中央罗盘边缘环绕一圈金丝，随时间顺时针消散。最后 3 秒金丝闪烁，罗盘中心文字柔和脉动，配合手机极轻微线性马达震动。

## 6. 听觉设计：空灵电子 (Audio Palette)

放弃真实的竹木碰撞声，采用**空间感极大、极其克制**的现代电子合成音效。

* **选牌/悬停：** 极轻微的合成器水滴声/马林巴琴泛音（涟漪感）。
* **出牌/落子：** 低沉柔和的电子木鱼/手碟单音，带长混响（深渊感）。
* **吃/碰/杠：** 轻微电子风铃扫频，落点为清脆的“磬”声（提神感）。
* **胡牌结算：** 深邃的低频下潜 (Sub-bass drop) 托底，接续空灵的古琴合成滑音（释放感）。
* **倒计时警告：** 模拟心跳频率的低频脉冲 (Pulse)。

## 7. 前端工程落地重点提示 (For Devs)

1.  **响应式适配 (Responsive)：**
    移动端横屏设备宽高比跨度极大（从 iPad 4:3 到折叠屏，再到 21:9 宽屏手机）。请广泛使用 `vw/vh` 结合 `clamp()` 函数控制麻将牌的最小/最大尺寸，避免牌体拉伸变形。
2.  **GPU 硬件加速：**
    所有涉及位移、放大的牌面交互，以及画卷展开、水墨晕染等全屏动效，**必须**使用 `transform`、`opacity`、`clip-path` 和 `mask` 属性。绝对禁止在动画帧中修改 `width`、`height`、`top`、`left` 导致全局重排 (Reflow)。
3.  **音频上下文 (Audio Context)：**
    为了实现“现代美术馆”般的宽广空间感，建议使用 Web Audio API，引入全局 `ConvolverNode` 叠加微弱的卷积混响。同时做好音频的节流防抖 (Audio Ducking)，防止连续出牌导致声音堆叠爆音。
